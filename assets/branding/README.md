# Mega Hub branding

The Mega Hub logo (a chrome "M" with a controller on a dark tile, blue edge fading into green) was supplied by
jjrussellite28-art; its provenance and the unchanged originals are described in
[`ui/assets/MEGA-HUB-LOGO.md`](../../ui/assets/MEGA-HUB-LOGO.md). It carries no Windows, Android or Apple mark, so one logo serves every platform.

Mega Hub is an independent fork of CouchHUD by kewe87. It does not use the CouchHUD name, logo or icon, so nobody
mistakes it for an official CouchHUD release. The CouchHUD artwork is not part of this repository any more.

| File | Used for |
|---|---|
| `png/` | App icon sizes 16–512 px (small sizes: the "M" and controller on a dark tile; large sizes: the full logo) |
| `icon-small.svg` | Icon wrapper for small sizes |
| [`../../docs/logo.png`](../../docs/logo.png) / `.svg` | The full logo with its "Mega Hub Launcher" label |
| [`../../docs/banner.png`](../../docs/banner.png) / `.svg` | Banner (1520×400) |
| [`../../docs/social-preview.png`](../../docs/social-preview.png) / `.svg` | GitHub social preview (1280×640), cut from the wide picture, which is also the startup-screen background (`ui/assets/mega-hub-hero.jpg`) |
| `../../installer/wizard-*.bmp` | Pictures in the installer wizard |

The images were generated from the original logo file. The old `scripts/brand-render.mjs` rendered the former
CouchHUD vector artwork and no longer matches these files.

The logo is AI-generated (ChatGPT); the repository makes no claim of exclusive rights in it.
