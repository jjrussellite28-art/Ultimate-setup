# Mega Hub branding

The Mega Hub logo (a silver key-rocket with teal panels on dark blue) was supplied by jjrussellite28-art; its
provenance is in [`ui/assets/MEGA-HUB-LOGO.md`](../../ui/assets/MEGA-HUB-LOGO.md) and the unchanged original is
[`ui/assets/mega-hub-original.jpg`](../../ui/assets/mega-hub-original.jpg).

Mega Hub is an independent fork of CouchHUD by kewe87. It does not use the CouchHUD name, logo or icon, so nobody
mistakes it for an official CouchHUD release. The CouchHUD artwork is not part of this repository any more.

| File | Used for |
|---|---|
| `png/` | App icon sizes 16–512 px, the rocket on a dark rounded tile |
| `icon-small.svg` | Icon wrapper for small sizes |
| [`../../docs/logo.png`](../../docs/logo.png) / `.svg` | The full logo with its "Mega Hub" label |
| [`../../docs/banner.png`](../../docs/banner.png) / `.svg` | Banner (1520×400) |
| [`../../docs/social-preview.png`](../../docs/social-preview.png) / `.svg` | GitHub social preview (1280×640) |
| `../../installer/wizard-*.bmp` | Pictures in the installer wizard |

The images were generated from the original logo file. The old `scripts/brand-render.mjs` rendered the former
CouchHUD vector artwork and no longer matches these files.

The logo is AI-generated (Bing Image Creator); the repository makes no claim of exclusive rights in it.
