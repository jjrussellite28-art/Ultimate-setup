# Corresponding source

Project: https://github.com/jjrussellite28-art/mega-hub
License: GNU GPL v3 (LICENSE).

For a binary distribution, supply its exact source archive alongside that binary with equally convenient access,
at no additional charge. The preparation workflow creates mega-hub-source-<commit>.zip using git archive
of the checked-out commit. It contains the tracked source, installer scripts, workflow and notices.
Do not substitute a changing default-branch link for the source of a specific installer.

BUILD-COMMIT.txt in the binary output records the source commit. Keep the source archive accessible for as long
as required by your chosen GPL distribution method. Include any required source of bundled covered dependencies,
their notices, and any required Installation Information; the project archive alone may not cover every component.

Build prerequisites and commands: README.md and .github/workflows/build.yml.
Signing secrets are not included. Document the procedure for building and installing modified versions,
including any user-controlled trust configuration needed for applicable GPL user-product obligations.
