Mega Hub – before you start

Mega Hub is a console-style interface for your Windows PC on the TV.

What this setup does
• Installs Mega Hub to C:\Program Files\MegaHub (a protected folder only administrators can change).
• Installs the Microsoft WebView2 Runtime if it is missing; Mega Hub needs it for its interface.
• Creates a Start menu entry, and optionally a desktop icon and autostart.

What this setup does NOT do
• It doesn't change how you sign in to Windows, doesn't replace the desktop and doesn't pause services.
• Mega Hub starts in app mode: an ordinary full-screen app. Shell replacement, couch lock, automatic sign-in and services only become available once you choose shell mode inside Mega Hub. Every change is listed there under "What Mega Hub changes in Windows".
• Mega Hub runs without administrator rights. Windows asks whenever something needs them.

Uninstall
Uninstalling restores what Mega Hub changed in Windows (shell entry, Task Manager policy, scheduled tasks, firewall rule) and asks whether your settings should be deleted. Emergency at any time: hold Ctrl + Shift (or LB + RB + View on the controller) for about 1.5 seconds while Mega Hub starts. Windows locks, and after you sign in with the account's Windows password the normal desktop comes back.

Damaged settings
If %APPDATA%\MegaHub\config.json is damaged, Mega Hub runs locked (no game starts) and writes nothing to the file. The way out: repair config.json or put it back. Deleting config.json alone does not start over; for that, remove the whole folder %APPDATA%\MegaHub (play time and profiles go with it). The config.json.broken file next to it is only a copy.

Disclaimer and privacy
Mega Hub is free software (GPL-3.0) without any warranty; use at your own risk. No telemetry, no account. The full texts are shown at the first start and under Settings › Info (currently in German).

Windows or browser warning
When you download or start this setup, Windows (SmartScreen) or your browser may say it "isn't commonly downloaded", "unknown publisher" or even "unsafe". That is normal for a new, free, independent program that is not signed with a paid certificate; it does not mean the file is a virus. Mega Hub is open source (GPL-3.0) and has no cheating or harmful code. If you downloaded it from the official Mega Hub page on GitHub, you can continue: choose "More info" and then "Run anyway".
